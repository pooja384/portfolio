# Pooja Kumari — Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `pooja-portfolio` folder in VS Code.
3. Use the Live Server extension to open `index.html`.

## Contact form
The form submits through FormSubmit to `poojamehta02000@gmail.com` without navigating away from the portfolio. On the first submission, FormSubmit sends an activation email to that inbox; confirm it before expecting contact messages to be delivered.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Your site will be available at `https://your-username.github.io/`.
